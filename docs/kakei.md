# 家計タブ（日々の収支と、月・年の振り返り）の検討

2026-10-07に決定。暮らしタブの「特別費」（docs/home.md §5.4・§10.3）を、家計全体を扱う **「家計」タブ** に広げる。

結論を先に書く。

- **Zaim は口座・証券の連携だけにし、今ある資産をざっくり見る用に絞る**（無料会員のままでよい）。
  **日々の収支はかぞく手帳に入れる**（§1）
- 目的は**振り返り**。生活費と特別費が毎月いくらで、目標とどれだけ離れたか（どこがプラス・どこがマイナスか、
  その要因は何か）を、**月ごと・年ごとに具体的に分かりやすく見られる**ようにする（§4・§5）
- 振り返れなかった原因は4つと見た（§1.2）。いちばん大きいのは**特別費が月の比較を乱していた**こと。
  生活費（月の予算）と特別費（年の予定）を**分けて比べる**
- **家計は独立したタブ**にする（毎日入れるため。6タブ）。暮らしタブのメニューからは特別費を外す（§2）

---

## 1. 方針

### 1.1 Zaim との分担（2026-10-07に決定。docs/home.md §5.2 を置き換える）

| 役目 | 置き場所 | 理由 |
| --- | --- | --- |
| 銀行・証券の残高（今ある資産） | **Zaim（無料会員）** | 口座の自動取得はZaimにしかできない（home.md §5.1）。無料会員でも連携の数に制限は無い |
| 日々の支出・収入の記録 | **かぞく手帳** | カードはもともと手入力（財布方式）。夫婦で同じ記録を見られる |
| カードの月末の照合 | **かぞく手帳** | 今の財布方式（日々入れる → 月末にカードの明細と合計を比べる → 合えば締める）をそのまま移す |
| 生活費の月の予算・特別費の年の予定 | **かぞく手帳** | 振り返りの「目標」になる |
| 月・年の振り返り | **かぞく手帳** | 今いちばん困っていること |

- Zaim の手入力の記録・CSVは取り込まない（移し替えは種類と予算だけ。§6）
- 口座から引き落とされる固定費（住居費・ローン・光熱費・通信・保険など）と給料は、**毎月自動で記録**し、
  額が変わるもの（光熱費など）だけ Zaim の口座を見て直す（§3.3）

### 1.2 振り返れなかった原因と、その手当て

| 原因 | 手当て |
| --- | --- |
| 特別費が月によって大きくぶれ、月の予算と比べても何がずれたか分からない | 生活費は**月の予算**、特別費は**年の予定（月ごと）**と、別々に比べる |
| 差の要因が記録に残らない | 差の大きい大分類は**内訳（小分類）と、その月の大きい記録の上位3件**を自動で出す。月に**一言メモ** |
| 振り返る場が無い（月末の照合で終わる） | 月が替わったら「先月の締め」: **カードの照合 → 振り返り → メモ** を1つの流れにする |
| 口座引き落としの固定費がアプリに無く、生活費の合計が合わない | 固定費・給料を**毎月自動で記録**する |

## 3. 記録

### 3.1 種類（2026-10-07に決定。Zaim のカテゴリをもとにする）

| まとまり | 大分類（予算を置く単位） | 小分類 |
| --- | --- | --- |
| **生活費** | 住居費・食費・光熱費・日用品・雑貨費・交通費・通信費・医療費・おしゃれ費・娯楽・子ども費（子の名前の大分類）・その他（11個） | 大分類ごとに数個（例: 食費＝食料品・外食・嗜好品、その他＝お小遣い・仕送り・ローン・保険・使途不明金…） |
| **特別費** | 特別費の項目（home.md §5.4 の `special_items`。種類＝住居費・車維持費・保険・税金・通信費・お祝い・学費・家具家電・季節対策・冠婚葬祭・旅行・子ども・その他） | – |
| **収入** | 給料など（毎月）。賞与は特別収入（`special_items` の `kind = 'income'`） | – |
| **貯金** | 貯金用の出金元（口座）への振替。**支出とは分ける**（月の目標を置く。§3.2） | – |

- 名前・並びは家族で変えられる（大分類・小分類の追加・名前の変更・並べ替え・使わなくする）
- **予算は大分類に置く**（年度ごとの月額。年度は4月始まりで特別費と同じ）。**入力は小分類を1タップ**で選ぶ
  （大分類の見出しの下に小分類のチップを並べ、押すと大分類も決まる。よく使うものを上に）

### 3.2 1件の記録（2026-10-07に決定。**Zaim を踏襲し、細かい部分だけ変える**）

1件の記録＝**記録の詳細**（支出／収入／振替・日付・出金元・お店）＋**品目の一覧**（品目ごとに金額・種類・品名・メモ）。
1回の買い物を種類ごとに分けられる（例: ドラッグストアで 医療費 › 薬・日用品・子ども費 を1件の記録に）。合計は品目から自動。

- 画面の流れ（Zaim と同じ）: 「＋」→ **記録の詳細** → 品目を押す／「品目を追加する」→ **品目**（**電卓はここで初めて出る**。
  ＋−×÷で計算できる）→ 種類を押す → **種類の選択**（大分類 › 小分類）。出金元・お店はそれぞれ**選ぶ画面**へ
- **品目の画面では、同じ種類の品目を何行でもまとめて記録する**（2026-10-07に決定）。行＝品名・個数（−＋）・単価・金額。
  選んだ行の金額（単価）を電卓で直す。下に小計。記録の詳細では、品目を**種類ごとにまとめて**1行で見せる（中の品名を下に小さく）
- **「日用品から選ぶ」ボタン**（2026-10-07に決定。品目の画面に候補を前もって並べない。シンプルにするため）:
  品目の画面に「日用品から選ぶ」と「行を追加」の2つのボタンだけを置く。「日用品から選ぶ」を押すと**日用品の台帳の一覧画面**
  （`household_products`。食品も含めた「毎月必ず買うもの」）へ移り、品名で探す・はじめは今の種類の品だけ（「すべて」で全部）。
  印をつけて個数を決め、「n品を入れる」でまとめて行にする（品名・いつもの値段・個数）。
  保存すると、台帳の「いつもの値段」を今回の単価に更新し、台帳には「いつ・何個・いくらで買ったか」が残る（docs/home.md §4.5）。
  台帳に無いものは「行を追加」で品名を打つ
- **出金元**: 家族で登録する（カード・財布・口座・プリペイド など。Zaim の「出金元の選択」と同じ並び）。前回のものを既定にする
- **お店**: 選ぶ画面で、検索と「最近使ったお店」（前に入れたお店から）。位置からの候補は出さない
- **振替**: 出金元 → 入金先（例: 生活費用の口座 → 貯金用の口座）。**入金先が貯金用の出金元なら「貯金」として数える**。
  ほかの振替（口座からカードの引き落としなど）は集計に入れない
- **Zaim から変えるところ**
  - 種類の選択の上に**よく使う小分類**、各大分類に**今月の残り**。品目で種類を選ぶと、その大分類の今月の残りが出る
  - **特別費は、その年度の予定から選ぶ**（まだ済でない予定を上に。選ぶと予算の額が入る）。これが特別費の「済」になる
    （特別費の実績 `special_actuals` は、この品目に移す。§6）。予定に無い特別費は項目を足して記録する
  - 置かないもの: 電話番号・時刻・タグ・写真・「常に集計に含める／含めない」（振替は集計に入れない、で足りる）

### 3.3 毎月自動で記録するもの（固定費・給料）

- 「毎月◯日・種類・額・払い方」を登録しておくと、その日に記録を作る（前回の額で）。額が変わるものはあとで直す
- 同じ月に二重に作らない（登録と月の組み合わせで1件）

### 3.4 カードの月末の照合（今の財布方式）

- カードで払った記録は、**出金元（カード）ごと**にその月の合計として積み上がる（Zaim のマイナス残高にあたる）
- 月が替わったら、カードごとに明細の合計を入れる → 合計が合えば「締める」（合わなければ差額を出し、記録を見直す）
- 締めた月の記録は、締めを外すまで直せないようにする（あとから合計が変わらないように）

## 4. 振り返り

### 4.1 月の振り返り（「月」）

上から順に、**結論 → 要因 → メモ**。

1. **結論**: **月の収支＝収入 − 生活費 − 貯金**（予算どおりなら残る予定だった額と比べて ± を出す）と、
   **特別費が予定どおりか**を分けて出す。**特別費は月の収支に入れない**（年払いの月に毎月の収支が大きく崩れ、
   生活費の良し悪しが見えなくなるため。特別費は賞与などの特別収入と年で釣り合わせる。§4.2）
2. **生活費**（2026-10-07に決定。**案Cのタイルの見た目に、案Aの並びと要因を合わせる**）: 大分類ごとのタイル（2列）。
   タイルには**使った割合の輪**・大分類名・**超えた額／残り額（大きく）**・実績 / 予算。**予算を超えた順**に並べ
   （超えたものは淡い赤の輪と枠、金額は赤）、予算どおり・残りのあるものが続く。
   タイルを押すと、その段のすぐ下に**要因**が開く: 小分類ごとの差（帯つき）と、その月の大きい記録の上位3件（日付・小分類・お店／メモ）、
   「この大分類の記録をすべて見る」
3. **特別費**: その月の予定と実績（済・まだ・予定外）。予算どおりか
4. **貯金**: 目標と実績
5. **メモ**: その月の一言（要因・来月気をつけること）
- 月の締め（§3.4）を済ませると、この画面に入る

### 4.2 年の振り返り（「年」）

- 月ごとの「生活費の差・特別費の差・残り」の並び（棒グラフ）と、年間の合計
- 大分類ごとの年間の予算・実績・差（どこで年間を通して超えているか）
- **特別費の年の流れ**（docs/home.md §10.3 の作り直しをここに入れる）: 月ごとの棒グラフ、これから払う、月別／種類別、
  これから5年の見通し
- 月のメモを年の中で読み返せる

## 5. データ（案。実装のPRで確定する）

```
money_categories  種類。 id / family_id / group('living'|'income') / parent_id(null=大分類) / name / position / archived_at
money_budgets     予算。 id / category_id(大分類) / fiscal_year / monthly_amount（貯金の目標は出金元に持つ）
money_wallets     出金元。 id / family_id / name / type('card'|'cash'|'bank'|'prepaid'|'qr') / is_saving / saving_target /
                  position / archived_at
money_records     記録の詳細。 id / family_id / kind('expense'|'income'|'transfer') / occurred_on / wallet_id /
                  to_wallet_id(振替の入金先) / store / recurring_id / created_by
money_items       品目（1行）。 id / record_id / amount / category_id(小分類か大分類) /
                  special_item_id・special_plan_id(特別費のとき) / product_id(日用品の台帳。任意) / quantity / unit_price /
                  name / memo / position
money_recurring   毎月の記録。 id / family_id / kind / day / wallet_id / to_wallet_id / store / 品目（種類・額）
money_months      月のメモ。 family_id / month / note
money_card_closes カードの照合。 wallet_id / month / statement_amount / closed_at
```

- 全部 `family_id` 単位のRLS（`current_family_id()`）
- 特別費の項目・予定は今の `special_items`・`special_plans` のまま。特別費の品目は `category_id` を持たず、
  `special_item_id`（と予定にひも付くときは `special_plan_id`）を持つ
- 振替の記録は品目を1つ持つ（金額だけ。種類なし）
- 日用品の台帳 `household_products` に、その品を記録するときの種類 `money_category_id`（小分類）を足す。
  「日用品から選ぶ」の一覧のはじめの絞り込みに使う
- 数え方（年度・月の集計・差・要因の上位）は mobile・PWA で同じ中身の `moneyUtils.ts`（テストつき）

## 6. 移し替え

- **種類と予算**: Zaim のカテゴリと妻のシートの「月々大分類・小分類」の予算から、**一度だけのSQL**で入れる
  （家族の私的なデータをリポジトリに残さない。home.md §3.4 と同じ）
- **特別費の実績**（`special_actuals`）: migration で `money_records`・`money_items` へ移す（行を移すだけで、中身の値はリポジトリに書かない）。
  移したあとは `special_actuals` を消す
- Zaim の過去の記録は移さない。かぞく手帳での記録は、使い始めた月から
